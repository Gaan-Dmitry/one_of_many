# Сайт проекта

`index.php` — веб-приложение для мира «Век Истока». Оно показывает ускоренное время мира, даёт редактор для написания истории, событий, флоры и фауны, сохраняет записи в `Site/data/stories.json` и отображает их в общей хронике.

## Markdown-база мира

На странице есть отдельный блок «Markdown-файлы мира». В нём можно:

- выбрать любой `.md`-файл проекта из списка;
- просмотреть простой HTML-превью markdown-содержимого;
- отредактировать файл и сохранить его обратно в репозиторий;
- создать новый файл по безопасному относительному пути, например `05_STORIES/Новая_сцена.md`.

Сайт читает только markdown-файлы внутри проекта и не показывает служебные папки вроде `.git`, `.obsidian`, `vendor`, `node_modules` и `Site/data`.

## Подключение AI-помощника

По умолчанию кнопки AI формируют готовый промпт и показывают инструкцию по подключению. Чтобы включить обращение к Alibaba Cloud Model Studio / DashScope-compatible API, задайте переменные окружения на сервере:

```bash
export DASHSCOPE_API_KEY="ваш_ключ"
export DASHSCOPE_MODEL="qwen-plus"
export DASHSCOPE_API_ENDPOINT="https://dashscope-intl.aliyuncs.com/compatible-mode/v1/chat/completions"
export DASHSCOPE_API_TIMEOUT="20"
```

`DASHSCOPE_MODEL`, `DASHSCOPE_API_ENDPOINT` и `DASHSCOPE_API_TIMEOUT` необязательны: в приложении уже заданы значения по умолчанию. Если API отвечает таймаутом, проверьте регион endpoint, доступность модели и ключ; при необходимости увеличьте `DASHSCOPE_API_TIMEOUT` до 60 секунд.

AI-помощник получает контекст из markdown-файлов проекта: открытый MD-файл добавляется подробнее, остальные файлы лора, мира, событий и историй добавляются выдержками, чтобы подсказка не противоречила базе мира.

## Хранение записей

Приложение создаёт папку `Site/data` автоматически. Для работы на хостинге убедитесь, что PHP-процесс может записывать в эту папку и в те markdown-папки, которые планируется редактировать через сайт.

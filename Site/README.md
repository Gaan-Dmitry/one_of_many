# Сайт проекта

`index.php` — веб-приложение для мира «Век Истока». Оно показывает ускоренное время мира, даёт редактор для написания истории, событий, флоры и фауны, сохраняет записи в `Site/data/stories.json` и отображает их в общей хронике.

## Подключение AI-помощника

По умолчанию кнопка «Попросить AI помочь» формирует готовый промпт и показывает инструкцию по подключению. Чтобы включить обращение к Alibaba Cloud Model Studio / DashScope-compatible API, задайте переменные окружения на сервере:

```bash
export DASHSCOPE_API_KEY="ваш_ключ"
export DASHSCOPE_MODEL="qwen-plus"
export DASHSCOPE_API_ENDPOINT="https://dashscope-intl.aliyuncs.com/compatible-mode/v1/chat/completions"
```

`DASHSCOPE_MODEL` и `DASHSCOPE_API_ENDPOINT` необязательны: в приложении уже заданы значения по умолчанию.

## Хранение записей

Приложение создаёт папку `Site/data` автоматически. Для работы на хостинге убедитесь, что PHP-процесс может записывать в эту папку.

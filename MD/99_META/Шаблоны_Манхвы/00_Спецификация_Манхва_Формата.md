# Спецификация архитектуры Манхвы: Арка -> Глава -> Сцена -> Фрейм

Данная система позволяет вести сюжет мира Века Истока как программную архитектуру. Каждый уровень иерархии имеет чёткий контракт данных (Frontmatter) и разметку, понятную художнику-иллюстратору и нейросетевым пайплайнам (Midjourney / Stable Diffusion / Flux / LLM).

```
[ АРКА (Сезон/Глобальный конфликт) ]
   └── [ ГЛАВА (Эпизод для вертикального вебтун-скролла) ]
          └── [ СЦЕНА (Локация + Драматический бит) ]
                 └── [ ФРЕЙМ / КАДР (Панель: Ракурс, Арт, Персонажи, Диалоги, SFX, AI-промпт) ]
```

---

## 1. Уровень "АРКА" (Arc)
- **Цель:** Задает глобальную арку персонажей, макро-конфликт фракций, статус мира и временной интервал.
- **Связи:** [[Глобальный таймлайн]], [[Активные события]], участвующие [[Фракции - Кланы Двуречья|фракции]].

## 2. Уровень "ГЛАВА" (Chapter)
- **Цель:** 40–70 вертикальных панелей (фреймов), рассчитанных на темп непрерывного скролла (webtoon scroll pacing). Содержит хук в начале, кульминацию и клиффхэнгер в финале.
- **Параметры:** Эмоциональный темп (Pacing), цветовая гамма эпизода (Color script), задействованные локации.

## 3. Уровень "СЦЕНА" (Scene)
- **Цель:** Непрерывный отрезок времени в одной локации. Раскрывает конкретное действие: диалог, бой, культивацию, тактическое перемещение.
- **Параметры:** Атмосфера, освещение, погодные условия, участвующие персонажи с рангами энергии.

## 4. Уровень "ФРЕЙМ" (Frame / Panel)
Базовая неделимая единица манхвы. Содержит 7 обязательных компонентов:
1. **Тип плана и ракурс:** (Close-up, Wide shot, Extreme Low-Angle, High-Angle Bird Eye, Vertical Scroll Cut).
2. **Визуальное описание кадра:** Позы, мимика, окружение, динамические линии движения (Speedlines).
3. **FX Истока и Ауры:** Свечение каналов, цвет и форма стихии, плотность ауры согласно [[Профили силы|профилю]].
4. **Текстовые пузыри (Speech Bubbles):** Реплики, выкрики, системные оповещения.
5. **Внутренний монолог / Нарратив (Caption Boxes):** Мысли героя, закадровый голос рассказчика.
6. **Звукоподражание (SFX / Sound Effects):** Корейские/русские звуковые эффекты (ДОННН, ШШШУХ, БУММ).
7. **Промпт для ИИ генерации (AI Prompt):** Англоязычный структурированный промпт для генератора картинок (Flux/Midjourney) с негативными тегами и указанием стиля манхвы.
